Controls how the branch list is fetched from the repository.

  • Enabled (default): Uses ls-remote. Very fast, no data is downloaded, but branches are sorted alphabetically.
  • Disabled: Fetches only the latest commit of each branch into a cache repository on the controller ($JENKINS_HOME/caches/active-git-branches) and sorts branches by commit date. The first fetch takes longer; later refreshes only download changed branch tips.

In both modes the result is cached. Opening "Build with Parameters" shows the cached list immediately and refreshes it in the background at most once per minute (configurable with the system property io.jenkins.plugins.activegitbranches.ActiveGitBranchesParameterDefinition.refreshIntervalSeconds).
